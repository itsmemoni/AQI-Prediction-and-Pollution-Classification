# Air Quality Index (AQI) Prediction and Pollution Level Classification Using Machine Learning

## Project Description
This project focuses on predicting the Air Quality Index (AQI) and classifying pollution levels using Machine Learning techniques.

## Objectives
- Predict Air Quality Index values.
- Classify air pollution into different levels.
- Help users understand air quality conditions.

## Technologies Used
- Python
- Machine Learning
- Pandas
- NumPy
- Scikit-learn
- Flask
- HTML
- CSS
- JavaScript

## Project Modules
1. Dataset Collection
2. AQI Prediction
3. Pollution Level Classification
4. Website and Dashboard Development
